# argenta-licencias

Lista de computadoras autorizadas para usar [Argenta](https://github.com/Fercho-Fercho/Argenta).
Repositorio separado del código fuente a propósito: la app lo lee por HTTPS
directo (`raw.githubusercontent.com`), sin token, y agregar/quitar una
computadora no requiere recompilar ni publicar una versión nueva de la app.

Ver el README de Argenta, sección "Licencia por computadora autorizada",
para cómo editar `autorizadas.json`.
